technicalNotes: "The Next.js frontend uses a typed Axios service layer; upload responses are cached in sessionStorage so the results page renders immediately. `NEXT_PUBLIC_API_URL` is baked in at Docker build time for standalone Cloud Run deployment. The Django REST API runs pandas-based profiling synchronously on upload, then offloads AI work to Cloud Tasks workers (`ai_insights`, `ai_chat`, `chart_generation`). Clients poll `/api/tasks/{id}/` until completion. Files live in Google Cloud Storage with signed URLs; auth uses JWT with refresh rotation across five login channels."
