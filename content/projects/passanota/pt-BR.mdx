name: "PassaNota"
tagline: "Cada nota registrada. Cada despesa sob controle."
overview: "PassaNota é uma plataforma B2B de controle de despesas para empresas brasileiras. Times fotografam notas fiscais no desktop ou em dispositivos móveis pareados; um pipeline de vision LLM extrai dados estruturados (fornecedor, itens, totais e datas) sem digitação manual. Gestores têm dashboards com tendências de gasto, breakdown por categoria e produtos mais frequentes, enquanto operadores capturam notas em campo. O sistema oferece multiempresa, acesso por papéis e tooling de admin de plataforma, implantado no GCP Cloud Run com auth Supabase e IAM serviço-a-serviço entre frontend e API."
highlights:

  - "Design SaaS multi-tenant: papéis gestor/operador, pareamento QR + PIN, visão admin da plataforma"
  - "Arquitetura split: frontend Next.js (`passanota-web`) e backend FastAPI (`passanota-api`) no GCP"
features:
  - "Captura de notas com IA via upload ou câmera ao vivo com detecção de documento"
  - "Processamento assíncrono em background com tracking de status via Cloud Tasks"
  - "Dashboard de gastos: totais, ticket médio, comparação de períodos, gráficos por categoria e emissor"
  - "Lista paginada de notas com detalhe de itens e badges de confiança da IA"
  - "Edição manual de itens e categorização quando a extração precisa de correção"

  - "Suporte multiempresa com switcher e dados isolados por tenant"

  - "Auth passwordless via magic link Supabase com fluxo de completar perfil"
  - "Painel admin da plataforma: métricas por empresa, uso e gestão de tenants"
technicalNotes: "O app Next.js roteia todas as chamadas de API por um proxy BFF em `/api/proxy/*`, encaminhando o Bearer Supabase, `X-Empresa-Id` e tokens de dispositivo. Em produção, o proxy troca o JWT do usuário por um ID token IAM do Cloud Run para alcançar o FastAPI privado. A API roda um pipeline assíncrono: guarda a foto no Supabase Storage, enfileira Cloud Tasks, pré-processa com OpenCV, extrai com vision LLM, persiste itens e normaliza categorias em SQL com keywords e embeddings. A busca semântica usa índices HNSW pgvector em embeddings multilíngues."
